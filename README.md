# Git Practice

This repository is created to practice Git and GitHub fundamentals.

## Topics Covered

- Git Repository Management
- Cloning Repositories
- Branching and Merging
- Staging and Committing Changes
- Pushing Changes to GitHub
- Creating Pull Requests

## Useful Git Commands

| Command | Purpose |
|---|---|
| git status | Check working tree status |
| git branch | List branches |
| git switch -c branch-name | Create and switch branches |
| git add . | Stage changes |
| git commit -m "message" | Commit changes |
| git push | Push changes to remote repository |
| git pull | Fetch and integrate remote changes |

## Learning Objective

Understand the basic Git workflow and collaborative development process using GitHub.
